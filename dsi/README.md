# Paperfive Pocket Camera - DSi v17

[Download file .nds](paperfive_pocket_camera-v17.nds?raw=true)

v17: album membuka foto terbaru dahulu, preview dipacing lebih stabil, dan
filter awal adalah **OFF**. Tombol L atau R tetap mengambil foto; filter
dipilih melalui palette touchscreen.

## Instalasi

1. Matikan Nintendo DSi / DSi XL, lalu hubungkan SD card ke komputer.
2. Salin `paperfive_pocket_camera-v17.nds` ke SD card, misalnya ke `/roms/nds/`. Hanya file .nds ini yang diperlukan untuk aplikasinya; jangan hapus file TWiLight Menu++ yang sudah ada.
3. Eject SD card dengan aman, pasang kembali, lalu buka TWiLight Menu++.
4. Jalankan ROM dalam **DSi mode**. Kamera tidak tersedia pada DS / DS Lite atau saat berjalan dalam DS mode.

## Kontrol

- L, R, A, atau tombol merah: ambil foto (sekali per tekan, saat di kamera).
- Palette touchscreen: ganti filter. L / R tidak lagi mengganti filter.
- Kiri / kanan: contrast; atas / bawah: brightness.
- Slider layar sentuh: brightness dan contrast.
- Flip Lens atau X: kamera depan / belakang.
- Album atau START: buka album thumbnail.

## Foto dan fitur

Foto disimpan sebagai JPG di folder `/paperfive_camera/` pada media penyimpanan yang aktif. Aplikasi memilih SD DSi jika tersedia; folder dibuat otomatis. Tunggu indikator penyimpanan berhasil sebelum keluar atau mematikan konsol.

Filter awal adalah OFF agar tampilan kamera natural. Palette menyediakan Pocket,
Mono, Hard, Sepia, dan Dither setelah dipilih. Bingkai NINTENDO CAMERA,
animasi tombol, serta titik merah berkedip saat capture tetap tersedia.

Jika album kosong, pastikan foto berhasil disimpan dan SD card dapat ditulis. Jika kamera hitam, pastikan memakai DSi mode pada konsol DSi.
